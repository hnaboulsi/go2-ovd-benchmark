# YCB assets

The pipeline downloads only the official Google 16K textured meshes for YCB `054_softball` and `055_baseball`. The archives are not committed. `manifest.yaml` pins their URLs, SHA-256 hashes, mesh hashes, and measured extents.

The YCB Object and Model Set is distributed under Creative Commons Attribution 4.0. Cite B. Calli et al., "Benchmarking in Manipulation Research: Using the Yale-CMU-Berkeley Object and Model Set," IEEE Robotics & Automation Magazine, 2015.
