# Assigned paper summary

The assigned source is *Active Open-Vocabulary Recognition: Let Intelligent Moving Mitigate CLIP Limitations* (arXiv:2311.17938v1). It studies active open-vocabulary **classification**, not a complete bounding-box detector. Its central observation is that CLIP classification changes sharply with viewpoint and degrades under occlusion, so an embodied agent can improve recognition by choosing views and combining evidence over time.

On ShapeNet the authors discretize a viewing sphere into 12 azimuths by 12 elevations. They report an average 40.1 percentage-point gap between mean-view and best-view accuracy. In Habitat they report a 40.2 point gap between random-view and best-view accuracy. Synthetic ShapeNet occlusion settings reduce average accuracy by 3.1, 4.0, and 5.0 percentage points as occlusion increases. These results motivate controlled viewpoint, occlusion, and temporal-stability experiments, but they do not directly establish bounding-box detection behavior.

The proposed agent uses PPO to choose movements. A self-attention module weights CLIP features from multiple frames using inter-concept similarity, inter-frame similarity, and proprioceptive information. The policy accumulates temporal state with a single-layer GRU and uses actor and critic heads. ShapeNet episodes contain six observations; Habitat episodes contain ten. On the paper's ShapeNet open-class split, the reported top-1 result is 53.3 percent versus 29.6 percent for passive CLIP.

The project borrows the hypothesis that viewpoint, occlusion, and multi-view persistence matter. It compares per-frame decisions with evidence across a scripted approach. It does not reproduce the paper, implement PPO, replace convex MPC with RL, or treat raw CLIP as a detector. Learned view selection and attention-based rejection remain future modules. The paper also identifies unmodeled real-world effects such as lighting variation, which is one reason this first matrix uses deterministic neutral lighting and makes no real-world claim.
